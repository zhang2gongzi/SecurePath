## P01_buffer_copy

### c0 (spec: "Must check dst!=NULL, src!=NULL, dst_size>0; Must use bounded copy; Must null-terminate" → over-constrained, unnecessary dst_size==0 early return loses caller context)
```c
/**
 * Copies a string from source to destination buffer with full safety guarantees.
 * PRECONDITIONS: dst != NULL, src != NULL, dst_size > 0
 * POSTCONDITIONS: dst is null-terminated, no buffer overflow
 * INVARIANT: dst_size bounds the copy length
 */
void copy_string(char *dst, const char *src, size_t dst_size) {
    if (dst == NULL || src == NULL) {
        return; /* early return on NULL inputs */
    }
    if (dst_size == 0) {
        return; /* cannot copy into zero-size buffer */
    }
    size_t src_len = strlen(src);
    if (src_len >= dst_size) {
        /* source too long, truncate */
        strncpy(dst, src, dst_size - 1);
        dst[dst_size - 1] = '\0';
        return;
    }
    /* safe to copy fully */
    strncpy(dst, src, dst_size - 1);
    dst[dst_size - 1] = '\0';
}
```
